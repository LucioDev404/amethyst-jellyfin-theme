# 📸 Screenshots

Add your captures here with these exact names — the main README references them:

| File | What to capture |
|---|---|
| `navbar.png` | Desktop navbar — hover a tab to show the purple underline (and one selected) |
| `card-hover.png` | Any row of cards with the mouse over one — centered violet play button |
| `home.png` | Home page — "My Media" tiles + a content row |
| `detail.png` | A movie/series detail page — pill action buttons |
| `player.png` | Player OSD visible — violet seek bar |
| `skip-intro.png` | The Skip Intro button during an intro |

Tips: use a dark scene for `player.png`; press `F12` → `Ctrl+Shift+P` →
"Capture full size screenshot" for clean full-page shots of `home.png` and
`detail.png`.
